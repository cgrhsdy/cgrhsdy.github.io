03专业方向

网络工程是一门围绕计算机网络的规划、组建、管理与安全展开的专业， 既要求理解网络通信的底层原理，也要求具备动手搭建和维护真实网络环境的能力。

  • 网络原理与协议 理解数据如何在网络中传输，掌握 TCP/IP 等核心协议
  • 路由与交换 网络设备的配置与调试，掌握网络互联的实际操作
  • 网络设计与综合布线 从需求出发规划网络结构，完成工程化的落地实施
  • 网络安全 了解常见攻击与防御手段，掌握系统与网络的安全加固
  • 程序设计基础 以 C / C++ 与 Python 为基础，具备用代码解决问题的能力
