# 个人主页

沈阳理工大学 · 信息科学与工程学院 · 网络工程专业 的个人静态主页。

## 在线访问

**https://cgrhsdy.github.io/**

## 项目说明

一个**纯静态**网页，不依赖任何后端服务，也不需要构建步骤：

- **零外部依赖** —— 不引用任何 CDN、在线字体、图标库或图片文件，断网也能完整显示
- **背景全部由代码生成** —— 星空、极光、山峦剪影都是 CSS 渐变与内联 SVG，没有图片素材
- **图标全部是内联 SVG**
- **响应式布局**，从手机到桌面都能正常浏览
- **可降级** —— 脚本被禁用或被拦截时自动跳过开场动画，直接展示全部内容
- **尊重系统偏好** —— 开启「减少动态效果」后不再播放动画
- **支持打印** —— 打印时自动隐藏按钮与背景、去掉阴影

## 访问流程

页面是「入口页 → 加载页 → 主页」的三段式结构：

1. **入口页** —— 展示标识、学校、学院与专业，点击「进入」按钮（或直接按 Enter / 空格）继续
2. **加载页** —— 网络拓扑动画，约 2.5 秒；加载过程中点击可跳过
3. **主页** —— 导航、首屏与七个内容板块

## 页面结构

| 区块 | 内容 |
| --- | --- |
| 导航 | 锚点导航 + 阅读进度条 + 回到顶部 |
| 首屏 | 标识、学校、学院、专业与三个数据统计 |
| 01 关于我 | 个人介绍、学习态度、兴趣，以及一张个人信息档案卡 |
| 02 基本信息 | 标识 / 年级 / 籍贯 / 学校 / 学院 / 专业 六张卡片 |
| 03 专业方向 | 网络工程的主要学习方向（6 个方向） |
| 04 技能与学习 | C 语言、Python、开发工具、计算机网络的学习进度 |
| 05 学习经历 | 从入学到现在的学习时间线（5 个阶段） |
| 06 未来规划 | 近期 / 中期 / 远期三个阶段的目标 |

## 使用的技术

- 语义化 HTML5 + CSS 自定义属性（变量）
- CSS 渐变与内联 SVG 绘制背景（星空、极光、山峦、网络拓扑）
- `IntersectionObserver` 实现滚动进场与技能条动画
- `requestAnimationFrame` 实现数字滚动
- `navigator.clipboard` 实现一键复制，并保留 `execCommand` 兜底

## 本地预览

直接用浏览器打开 `index.html` 即可，无需启动服务器。

如果想用本地服务器预览（更接近线上效果）：

```powershell
cd D:\play_do\personal-page
python -m http.server 8000
# 然后浏览器访问 http://localhost:8000
```

## 部署方式

通过 **GitHub Pages** 部署：仓库名为 `cgrhsdy.github.io`，
Pages 从 `main` 分支根目录发布，推送到 `main` 后会自动重新构建。

## 更新方法

修改 `index.html`、`style.css` 或 `app.js` 后：

```powershell
git add -A
git commit -m "更新个人主页"
git push
```

推送后约 1 分钟，线上页面会自动更新。
